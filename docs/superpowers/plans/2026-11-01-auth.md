# Auth (Email/Password) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add email/password auth with registration, email verification, login, logout, and a protected dashboard, backed by a local SQLite file.

**Architecture:** Remix-native. A SQLite `data-table` database holds `users` and a separate `user_passwords` table. Session middleware persists login state in a signed cookie. Credentials provider verifies email/password/verification. CSRF middleware protects form posts. Routes are `form()` pairs for login/register plus plain routes for verify/logout/dashboard.

**Tech Stack:** remix (router, middleware, data-table, data-schema, component), Bun.password (argon2id), SQLite (bun:sqlite via remix).

**Spec:** `docs/superpowers/specs/2026-11-01-auth-design.md`

## Global Constraints

- Package manager/runtime: Bun only; no new dependencies.
- Strict TypeScript; `verbatimModuleSyntax` (use `import type`).
- Conventional Commits for each task.
- Passwords hashed with `Bun.password.hash` (argon2id).
- Session cookie: name `__session`, signed with `SESSION_SECRET` (fallback `dev-secret-change-me`), httpOnly, sameSite `lax`, path `/`.
- Verification token expiry: 24 hours.
- Password minimum length: 8.

## Review Focus

- Unverified user attempting login must be rejected with a generic error (no email enumeration).
- Expired/invalid verification token must not verify or crash.
- Password hash must never appear in dashboard/user-loading code paths.
- CSRF token missing/invalid must reject POSTs.
- Logout must destroy server-side session state (regenerate id), not just unset one field.

import * as assert from 'remix/assert';
import { describe, it } from 'remix/test';

import { db, users, userPasswords } from './db.ts';

describe('db', () => {
  it('creates and reads a user without password hash', async () => {
    let id = crypto.randomUUID();
    await db.create(users, { id, email: 'a@b.com', email_verified: false, created_at: Date.now() });
    await db.create(userPasswords, { user_id: id, password_hash: 'hash', updated_at: Date.now() });
    let user = await db.find(users, id);
    assert.ok(user);
    assert.equal(user.email, 'a@b.com');
    assert.equal('password_hash' in (user as any), false);
  });
});
